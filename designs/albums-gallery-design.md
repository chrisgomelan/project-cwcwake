# Albums Gallery Page — Design Spec

Applies to:
- `/gallery/events/` 
- `/gallery/[category-name]/`

---

## 1. Album Image Card

The grid layout for specific photos within a category.

| Property      | Value                 |
| ------------- | --------------------- |
| Width         | `796px`               |
| Height        | `494px`               |
| Top Offset    | `100px`               |
| Left Offset   | `6px`                 |
| Border Radius | `30px`                |
| Rotation      | `0deg`                |
| Opacity       | `1`                   |
| Overlay       | `#0000001A` (10% Black) |
