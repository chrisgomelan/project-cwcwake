# Single Blog Post — Design Spec

Applies to: **Single Blog Post** template and related content sections.

Reference: `single-blog-design.png`

---

## Page Header & Background

The single blog post page should include:
-   **Breadcrumbs**: Navigation path for easy access back to previous sections.
-   **Backlink**: A "Back to Blogs" link/button.
-   **Background**: A tropical-themed background image/pattern applied to the page or header section.
