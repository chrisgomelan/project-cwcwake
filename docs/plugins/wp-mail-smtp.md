# WP Mail SMTP

[← Back to overview](../README.md)

This plugin helps WordPress send **email** reliably (forms, notifications, mail from plugins such as **Promo Mailer**).

## Routine check (when your role allows it)

1. In the left menu, open **WP Mail SMTP** (wording may read **Email** or similar depending on version).
2. Find the **email test** or **send a test email** option your team uses.
3. Send a test to an address you can open, and confirm it arrived (and check spam if needed).

## If mail stops working

1. Do **not** change API keys or DNS unless technical staff asked you to.
2. Note any on-screen error text, take a screenshot, and forward it to technical support or whoever manages the mail provider account.
