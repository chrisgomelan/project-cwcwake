# Glossary

[← Back to overview](README.md)

Short definitions for collaborators. Wording may differ slightly in your dashboard language.

| Term | Meaning |
|------|--------|
| **Admin / Dashboard** | The private WordPress back end after you log in. |
| **Block editor** | The modern page and post editor made of blocks (paragraphs, images, headings, etc.). |
| **Draft** | Saved work that is **not** shown to visitors until published. |
| **Featured image** | The main image attached to a page or post; rooms use **Room cover image**. |
| **Media library** | Central place for uploaded files (images, PDFs, etc.). |
| **Menu** | The list of links in the site header, footer, or sidebar, depending on the theme. |
| **Permalink** | The permanent web address of a page or post. |
| **Plugin** | An add-on that extends WordPress (email, SEO, rooms, cache, etc.). |
| **Publish / Update** | **Publish** makes new content live; **Update** saves changes to something already published. |
| **Slug** | The short, URL-friendly part of a link (often derived from the title). |
| **Theme** | Controls the overall layout and design of the public site. |
