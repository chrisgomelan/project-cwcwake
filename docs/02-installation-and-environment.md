# Installation and environment

[← Back to overview](README.md)

## What this page is *not*

This handbook does **not** teach server installation. Hosting, PHP, and database setup are handled by your technical contact or host.

## What you need as a maintainer

1. **The address of the live site** (what visitors type in the browser).
2. **The address of the WordPress admin** (dashboard), and your username.
3. **A supported browser** — current Chrome, Edge, Firefox, or Safari is fine.
4. **Agreement on where you work** — usually the **production** site. If your team also uses a separate “staging” or “preview” site, know which URL is which so you do not publish drafts to the wrong place.

## Local copies (optional)

Some developers keep a copy of the site on their own computer (for example with Local WP). That copy is for building and testing. **Editors and most maintainers** work only on the shared live or staging URL unless someone explicitly asks you to use a local copy.

## After big technical changes

When technical work finishes (theme change, plugin update, migration), do a quick **smoke check**: open the homepage, one inner page, and one room page if you use Accommodations. Report anything odd with the URL and a screenshot.
