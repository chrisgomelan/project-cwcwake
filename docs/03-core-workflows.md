# Core workflows

[← Back to overview](README.md)

These patterns apply to standard WordPress content. Room-specific work lives in [CWC Wake — Accommodations](plugins/cwc-accommodations.md).

## Pages and posts

1. In the left menu, choose **Pages** or **Posts**.
2. Click **Add New** or open an existing item from the list.
3. Edit the title and body. Use **Preview** before **Publish** or **Update**.
4. After publishing, open the page on the real site (not only inside the editor) to confirm it looks right.

**Draft vs published** — Drafts are not visible to the public until someone publishes them.

## Featured images and media

1. **Media → Library** — upload files once, then reuse them.
2. On a page or post, set a **featured image** when the design expects one (rooms use a **Room cover image**; see the Accommodations guide).

Prefer reasonably sized images so pages stay fast. If an image looks blurry, upload a slightly larger file rather than stretching a tiny one.

## Menus

1. **Appearance → Menus** (exact location can vary slightly by theme).
2. Add items from the left column, drag to order, assign to the correct menu location if your theme offers several.
3. Save the menu, then check the live site header/footer.

## Before you call it done

- [ ] Checked on desktop (and phone if you have time).
- [ ] Links you added actually open the right place.
- [ ] No placeholder text like “Lorem ipsum” left behind.
